# ✳ 돌려돌려 점심판

점심 고민을 가볍게 끝내는 한국어 메뉴 룰렛입니다. 설치나 API 키 없이 실행됩니다.

## 실행

`index.html`을 브라우저에서 열거나, 프로젝트 폴더에서 `npx --yes serve .`를 실행하세요.

## 기능

- 기본 메뉴 8개 및 직접 입력한 메뉴 (최대 20개)
- 메뉴별 추첨 포함/제외
- 룰렛 애니메이션과 결과 표시
- 가장 최근 당첨 메뉴 제외 옵션
- 최근 6회 추첨 기록과 브라우저 로컬 저장
- 모바일 화면, 키보드 조작, 모션 줄이기 설정 지원

## 구성

HTML, CSS, JavaScript만 사용하는 정적 웹입니다. 서버와 데이터베이스는 필요하지 않습니다. Google Fonts를 불러올 수 없으면 시스템 글꼴로 표시됩니다. 기록은 현재 기기·브라우저에만 저장됩니다.

GitHub Pages 등 정적 호스팅에서 루트 폴더를 배포할 수 있습니다. 룰렛 당첨 후 브라우저 위치 권한 또는 직접 입력한 지역을 기반으로 OpenStreetMap Overpass에서 실제 등록 식당을 검색합니다. 식당명, 기준 위치와의 직선거리, 등록된 음식 종류 및 주소를 카드로 보여줍니다. 지도나 길찾기 기능은 제공하지 않습니다. API 키는 필요하지 않습니다. 단, OpenStreetMap의 국내 식당·음식 종류 데이터는 누락될 수 있고 무료 공용 API 접속이 불안정할 수 있습니다. 가격·실시간 영업 여부는 제공하지 않습니다. 위치 권한은 HTTPS(또는 localhost)에서만 정상 작동하며, 위치 좌표는 식당 검색 요청에 사용되지만 앱이 저장하지 않습니다. 지역명 검색에는 Nominatim 공용 API를 사용하므로 과도한 자동 요청을 하지 마세요.
